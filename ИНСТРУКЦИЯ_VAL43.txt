    ИНСТРУКЦИЯ ПО ИСПРАВЛЕНИЮ ОШИБКИ VAL43 В VALORANT
═══════════════════════════════════════════════════════════

📁 СОЗДАННЫЕ ФАЙЛЫ:
────────────────────────────────────────────────────────────

1. Valorant_VAL43_Fix.bat - Полный патч (РЕКОМЕНДУЕТСЯ)
   • Останавливает все процессы Riot/Valorant
   • Удаляет временные файлы настроек
   • Перезапускает Vanguard
   • Сбрасывает сетевые настройки
   • Проверяет конфликтующие программы

2. Valorant_VAL43_Fix.ps1 - Расширенная PowerShell версия
   • Все функции .bat версии
   • Цветной вывод
   • Диагностическая информация
   • Детальные логи

3. Valorant_Quick_Fix.bat - Быстрое исправление
   • Только самые важные действия
   • Для срочных случаев перед игрой

═══════════════════════════════════════════════════════════
    КАК ИСПОЛЬЗОВАТЬ
═══════════════════════════════════════════════════════════

📌 СПОСОБ 1 - Базовый (.bat файл):

1. Нажмите ПКМ на "Valorant_VAL43_Fix.bat"
2. Выберите "Запуск от имени администратора"
3. Следуйте инструкциям на экране
4. Перезагрузите компьютер
5. Запустите Riot Client от имени администратора
6. Войдите в аккаунт и запустите Valorant


📌 СПОСОБ 2 - PowerShell (.ps1 файл):

1. Нажмите ПКМ на "Valorant_VAL43_Fix.ps1"
2. Выберите "Запуск с помощью PowerShell" или:
   - Нажмите ПКМ → "Открыть с помощью" → "PowerShell"
3. Если появляется ошибка политики выполнения:
   - Откройте PowerShell от администратора
   - Выполните: Set-ExecutionPolicy -ExecutionPolicy Bypass -Scope Process
   - Перетащите файл .ps1 в окно PowerShell
   - Нажмите Enter
4. Следуйте инструкциям
5. Перезагрузите компьютер


📌 СПОСОБ 3 - Быстрое исправление (Quick Fix):

1. Нажмите ПКМ на "Valorant_Quick_Fix.bat"
2. Выберите "Запуск от имени администратора"
3. Дождитесь завершения (5-10 секунд)
4. Запустите Valorant от имени администратора

    ЧТО ДЕЛАЕТ СКРИПТ
═══════════════════════════════════════════════════════════

✓ Останавливает процессы:
  • RiotClientServices.exe
  • Valorant.exe
  • VALORANT-Win64-Shipping.exe

✓ Останавливает и перезапускает службу Vanguard (VGC)

✓ Удаляет файлы настроек:
  • RiotClientPrivateSettings.yaml
  • RiotClientSettings.yaml
  • RiotGamesPrivateSettings.yaml
  Путь: C:\Users\[ИМЯ]\AppData\Local\Riot Games\Riot Client\

✓ Сбрасывает сетевые настройки:
  • netsh winsock reset - Сброс Winsock
  • netsh int ip reset - Сброс TCP/IP
  • ipconfig /release - Освобождение IP
  • ipconfig /renew - Обновление IP
  • ipconfig /flushdns - Очистка DNS кэша
  • netsh winhttp reset proxy - Сброс прокси
  • netsh advfirewall reset - Сброс брандмауэра

✓ Проверяет конфликтующие программы:
  • Bonjour (Apple сервис)
  • National Instruments
  • Guardian Browser
  • Anti Cheat Expert

    ДОПОЛНИТЕЛЬНЫЕ СОВЕТЫ
═══════════════════════════════════════════════════════════

🔧 ЕСЛИ ОШИБКА ПОВТОРЯЕТСЯ:

1. Проверьте статус серверов Valorant:
   https://status.riotgames.com/valorant

2. Удалите конфликтующие программы:
   • Панель управления → Программы → Удалить программу
   • Найдите: Bonjour, National Instruments
   • Удалите их

3. Переустановите Vanguard:
   • Удалите через: Панель управления → Riot Vanguard
   • Запустите Valorant - Vanguard установится автоматически

4. Проверьте целостность файлов:
   • Откройте Riot Client
   • Настройки → Valorant → "Инициировать полное восстановление"

5. Попробуйте проводное подключение:
   • WiFi может вызывать таймауты
   • Используйте Ethernet кабель


⚠️ ВАЖНЫЕ ЗАМЕЧАНИЯ:

• Скрипт НЕ удаляет игру или ваш прогресс
• Вам нужно будет заново войти в аккаунт Riot
• После скрипта ОБЯЗАТЕЛЬНА перезагрузка компьютера
• Всегда запускайте от имени администратора
• Закройте все программы Riot перед запуском


🔄 ПОРЯДОК ДЕЙСТВИЙ ПРИ VAL43:

1. Запустите Valorant_VAL43_Fix.bat от администратора
2. Дождитесь завершения
3. Перезагрузите ПК
4. Запустите Riot Client от администратора
5. Войдите в аккаунт
6. Запустите Valorant

Если не помогло:
7. Запустите скрипт ещё раз
8. Проверьте конфликтующие программы
9. Переустановите Vanguard
10. Обратитесь в поддержку Riot

Q: Безопасно ли использовать скрипт?
A: Да, скрипт использует только официальные Windows команды

Q: Удалится ли моя игра?
A: Нет, удаляются только временные файлы настроек

Q: Почему нужны права администратора?
A: Для управления службами Windows и сброса сетевых настроек

Q: Как часто можно запускать скрипт?
A: Сколько угодно, каждый раз перед запуском игры если нужно

Q: Что делать если скрипт не помог?
A: Попробуйте переустановить Vanguard или обратитесь в поддержку
